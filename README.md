<h1>Extract Date from URL</h1>

<p>This Python script helps you extract the date from a given URL by navigating to the page and looking for the specified HTML element containing the date.</p>

<h2>Usage</h2>

<ol>
    <li>Clone or download this repository to your local machine.</li>

    <li>Open a terminal or command prompt and navigate to the directory where you have saved the <code>main.py</code> file.</li>

    <li>Run the script by executing the following command:</li>

    <pre><code>python main.py</code></pre>

    <li>Follow the on-screen prompt to enter the URL of the page you want to extract the date from.</li>

    <li>The script will navigate to the URL, look for the specified HTML element, and extract the date.</li>

    <li>The extracted date will be displayed on the screen.</li>
</ol>

<h2>Example</h2>

<p>Here's an example of how the script can be used:</p>

<pre><code>Enter the URL: https://freecoursesite.com/ultimate-photoshop-training-from-beginner-to-pro-11/

Extracted date: 2025-01-17T11:05:39+05:30</code></pre>

<p>Now you have the extracted date from the specified URL.</p>
